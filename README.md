# ဟီဘရူးကျမ်းစာ — မြန်မာဘာသာပြန်ဆိုချက်

ဟီဘရူးကျမ်းစာ (Tanakh) ၏ အခန်းငယ်တစ်ခုချင်း ဘာသာပြန်ဆိုချက် —
မူရင်းအက္ခရာများကို သစ္စာစောင့်သည်။

## ဟီဘရူး ဦးစားပေး

ဤဘာသာပြန်သည် သင့်ကို ဟီဘရူးထံ ပို့ဆောင်ရန်ဖြစ်သည် — ၎င်း၏နေရာကို
ယူရန် မဟုတ်။ အမြဲဖတ်နေသည်မှာ ဟီဘရူးဖြစ်သည် — ၎င်း၏ဗျည်းများ၊
သရများနှင့် အမှတ်အသားများ။ အောက်ရှိ မြန်မာစာသည် ပြတင်းပေါက်
ဖြစ်သည်၊ အစားထိုးမှု မဟုတ်။ နှစ်ခုကွဲလွဲသည့်နေရာ၌ ဟီဘရူးက မှန်သည်။

## နာမတော်

လေးလုံးအက္ခရာနာမတော် ပေါ်လာသည့်နေရာတိုင်း၌ **ယာဝေ** ဟု
ရေးသည် — ၎င်း၏နေရာ၌ မည်သည့်ဘွဲ့မျှ မထား၊ မည်သည့်ယေဘုယျ
စကားလုံးမျှ မထား။ **ယေဟောဝါ** (ရောနှောပုံစံ) ဟု မရေး၊
**ထာဝရဘုရား** (ဘွဲ့ — နာမတော်မဟုတ်) ဟု မရေး၊ နာမတော်နေရာ၌
**ဘုရားသခင်** ကိုလည်း မထား။ နာမတော်သည် ရှိသည့်အတိုင်း၊
နေရာတိုင်း၌ ရပ်တည်သည် — နာမတော် ဘယ်နေရာ၌ရှိသည်ကို အမြဲ
မြင်နိုင်ရန်။

## အာလက်ဖ်-သော — ⟨את⟩

မြန်မာစာကြောင်းများတွင် ထိန်းသိမ်းထားသော **⟨את⟩** ကို တွေ့ရမည်။
ဟီဘရူး၌ אֵת သည် ကြိယာ၏ကံကို ညွှန်ပြသည့် စကားလုံးငယ်ဖြစ်သည်။
မြန်မာဘာသာ၌ ၎င်းနှင့်ညီမျှသော စကားလုံးမရှိ၊ ဘာသာပြန်အများစုက
၎င်းကို တိတ်တဆိတ် ဖယ်ရှားကြသည်။ ကျွန်ုပ်တို့သည် ၎င်းကို မြင်နိုင်ရန်
ကွင်းအတွင်း ထိန်းသိမ်းထားသည် — အကြောင်းမှာ ၎င်းသည် ဘာသာစကား၏
အထည်အလိပ်၏ အစိတ်အပိုင်းဖြစ်သောကြောင့်။ ဖျက်မည့်အစား ၎င်း၏
တည်ရှိမှုကို ပြသရန် ရွေးချယ်သည်။

## ⟨ကွင်း⟩ အတွင်းရှိ စကားလုံးများ

⟨ဤကဲ့သို့⟩ ကွင်းများသည် **ဟီဘရူး၌ မရှိသော** စကားလုံးများကို
အမှတ်အသားပြုသည် — မြန်မာစာကြောင်း ရပ်တည်နိုင်ရန် လိုအပ်သည့်
ဖြည့်စွက်ချက်များ။ ၎င်းတို့ကို အမှတ်အသားမပါဘဲ ရောမနှောမည့်အစား
ကွင်းအတွင်းထည့်သည် — မူရင်းဟီဘရူးစကားလုံးများနှင့် မြန်မာ
လိုအပ်ချက်က ဖြည့်သောစကားလုံးများကို အမြဲ ခွဲခြားသိနိုင်ရန်။
ကွင်းအတွင်းရှိ ဖြည့်စွက်စကားလုံးများသည်လည်း မြန်မာဘာသာဖြင့်သာ
ဖြစ်သည်။

## နာမတော်များနှင့် ဘွဲ့များ

သန့်ရှင်းသောအရှင်ကို ညွှန်းသည့် ဟီဘရူးစကားလုံးများ — **ဧလောဟိမ်**၊
**ဧလ်**၊ **ရှဒ္ဒိုင်**၊ **အဒေါနိုင်**၊ **ယာ** — ကို ၎င်းတို့၏
အသံအတိုင်း ရေးသည်။ စကားလုံးတစ်လုံးတည်းသို့ မချုံ့ပါ; တစ်ခုစီသည်
မိမိဝန်ကို သယ်ဆောင်သည်။ လူပုဂ္ဂိုလ်နှင့် နေရာအမည်များလည်း ဟီဘရူး
ပုံစံအတိုင်း: အဗ်ရာဟမ်၊ ယိတ်စဟာက်၊ ယာကောဗ်၊ မိုရှေ၊
ယေရုရှာလိုင်မ်။

## အမှတ်အသားပြုထားသော စကားလုံးများ

- **ဟေသက်ဒ်** (חֶסֶד) — ပဋိညာဉ်၏ သစ္စာရှိမေတ္တာ။ ရိုးရိုး
  "ကရုဏာ" မဟုတ်၊ ရိုးရိုး "မေတ္တာ" မဟုတ်။ ၎င်းကို အပြည့်အဝ
  သယ်ဆောင်နိုင်သော မြန်မာစကားလုံးတစ်လုံးတည်း မရှိ။
- **ရှီးအိုလ်** (שְׁאוֹל) — ဟီဘရူးပြောသည့်အတိုင်း သေသူများ၏နေရာ။
  "ငရဲ" မဟုတ်။
- **နေဖက်ရှ်**၊ **ရုအာခ်**၊ **ကာဗေါဒ်** — အခြေအနေအလိုက် (အသက်
  သို့မဟုတ် စိတ်ဝိညာဉ်၊ လေ သို့မဟုတ် ဝိညာဉ်၊ ဘုန်း သို့မဟုတ်
  အလေးချိန်) — စကားလုံးတစ်လုံးတည်း၌ သံမှိုမရိုက်ပါ။

## အခန်းငယ်တစ်ခုစီကို ၎င်း၏အလင်း၌

အခန်းငယ်တစ်ခုစီကို ၎င်း၏နေရာ၌ ပြောသည့်အတိုင်း ဘာသာပြန်သည် —
ဧလောဟိမ်သည် တစ်ပါးတည်းဖြစ်သည်ဟူသော ဟီဘရူးယုံကြည်ချက်အတွင်း
ဖတ်သည်။ နောက်မှလာသော အယူဝါဒများကို မထည့်; ဇာတ်လမ်း၏အဆုံးကို
၎င်း၏အစ၌ မဖတ်။ စကားလုံးများက ၎င်းတို့၏နေရာ၌ သယ်ဆောင်သည့်
အဓိပ္ပာယ်ကို သယ်ဆောင်ခွင့်ပြုခြင်း — ၎င်းသည် ရည်ရွယ်ချက်ဖြစ်သည်။

## ဖိုင်ဖွဲ့စည်းပုံ

အခန်းငယ်တစ်ခု၊ ဖိုင်တစ်ခု: အခန်းငယ်ကိုယ်တိုင်နှင့် ဟီဘရူး
စကားလုံးတစ်လုံးစီ၏ ဘာသာပြန်ချက် — ဟီဘရူးစကားလုံးတစ်လုံးစီကို
၎င်း၏မြန်မာစကားလုံးနှင့် ယှဉ်တွဲဖတ်နိုင်ရန်။
